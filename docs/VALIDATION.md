# 0.2 验证说明

本地测试在 Windows、Python 3.12 下执行，JSON 与 FAISS 配置各通过 41 项测试。GitHub Actions 另覆盖 Ubuntu Python 3.10 JSON、Ubuntu Python 3.12 FAISS 和 Windows Python 3.12 FAISS，并保存测试 XML 与评测报告。

回归覆盖：

- BM25 与向量融合、无关问题空召回、来源筛选、引用编号。
- 上传和手动录入后重建索引，并通过问答接口检索新文档；损坏 PDF 单文件失败不会中断其他文件。
- 中文目录中的 FAISS 保存和加载、JSON/FAISS 两种配置运行。
- WGS84 赤道 1° 距离约 111319.491 米、跨日期变更线距离、面积单位与顶点顺序、坐标往返转换。
- 越界坐标、非法单位、无效 EPSG、自交地块和无效 WKT 的接口错误状态。
- 未召回资料时跳过模型、异常模型响应和网络失败回到本地资料摘录。

36 条正例及 4 条无证据样本的详细结果见 `eval_report.md` 和 `eval_results.json`。默认 JSON TopK=4 的来源 Hit@K=1.0、MRR=0.9583、检索关键词覆盖率=1.0、离线回答关键词覆盖率=0.7986，无证据样本空召回率=1.0。

这些结果只描述仓库中的演示资料。真实大模型通过模拟响应与模拟网络异常验证适配逻辑；本次没有使用收费 API、外部采集或生产数据，也未声称完成分布式向量库、模型微调或工程测绘精度验收。
