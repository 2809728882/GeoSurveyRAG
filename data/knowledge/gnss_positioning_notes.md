# GNSS 单点定位与测绘知识

GNSS 单点定位通常处理 RINEX 观测文件和广播星历或精密星历，通过伪距观测方程解算接收机坐标与钟差。

关键步骤包括：

- 解析观测文件，提取历元、卫星号、伪距、载波相位和信噪比。
- 根据广播星历计算卫星位置，并进行卫星钟差改正。
- 构建观测方程，使用最小二乘迭代求解接收机三维坐标和钟差。
- 进行误差改正，包括电离层延迟、对流层延迟、地球自转改正和相对论效应。
- 使用 GDOP、PDOP、残差和可见卫星数评价定位质量。

在 LLM 应用中，GNSS 解算流程适合作为工具调用或代码助手场景：模型负责解释问题、选择算法路径、生成参数建议，确定性计算仍由 Python 或 MATLAB 程序完成。
