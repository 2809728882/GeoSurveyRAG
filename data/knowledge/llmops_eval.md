# LLM 应用评测与运维

LLM 应用从需求到上线需要完整质量闭环。RAG 系统常见评测指标包括：

- 召回命中率：检索片段是否包含回答所需事实。
- 上下文覆盖率：TopK 片段是否覆盖多个必要知识点。
- 忠实度：答案是否只依据上下文，不编造不存在的数据。
- 工具调用准确率：模型是否在需要空间计算时选择正确工具。
- 用户满意度：线上反馈、点赞点踩、人工复核结果。

Prompt 迭代应固定评测集，记录版本、变量、模型、温度、TopK、切片大小和召回阈值。线上可以通过 A/B 测试比较不同 Prompt 或不同检索策略，重点观察用户点赞率、追问率、平均响应延迟和 Token 成本。

部署层面建议使用 Docker 镜像、健康检查、结构化日志、请求耗时监控和成本统计。对于测绘生产系统，还需要关注数据权限、涉密数据隔离和审计留痕。
